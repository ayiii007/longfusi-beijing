# 隆福寺｜寺院、庙市与街区

北京隆福寺的历史地理展示：1452—2025沿革时间表、古今地图叠合与资料查证。

- [主站](index.html)：总述、沿革时间表、古今地图。
- [资料与查证](查证资料/index.html)：材料说明、照片、两通碑、沿革与地图依据。

使用纯HTML、CSS和JavaScript，无需安装依赖。下载仓库后用Edge或Chrome打开 `index.html` 即可。

## 材料与链接

仓库只附地图实际使用的17张照片、两张碑刻拓片、古图图层和必要文本、数据。完整本地资料保留在交付文件夹，不上传全部扫描书页、文献PDF和其他照片。

照片和资料链接优先使用本地文件，上传版未附的改用已记录的在线图源或来源页。在线图片无法加载时，仍可打开来源页。没有公开全文的书籍只提供书目信息，不标作全文；暂无可核实公开来源的材料保留说明，不提供失效链接。

古图默认使用寺院局部清晰版、20%透明度。清晰版经过处理，细部核对可切换原扫描。历史地点按古图约位，适合观察街巷变化，不作实测遗址坐标。

古图以独立图片加载，三张图层合计约1.95 MB，避免每次读取约13.85 MB的内嵌图像脚本。

## GitHub Pages

在仓库 `Settings → Pages` 选择 `Deploy from a branch`，使用 `main` 分支、`/(root)` 目录。本仓库已附 `.nojekyll`。

图源、摄影者及使用说明保留在照片窗口与查证站。现代道路数据来自OpenStreetMap，© OpenStreetMap contributors，ODbL。
